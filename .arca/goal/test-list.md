# `uni-spec` test plan

Verification for `US-01` through `US-12` is document inspection and written state tracing. Recovery checks `US-13` through `US-17` additionally exercise the restored repository CLI/build/test closure; they do not change the docs-only standard contract. `T-018` inspects the separately scoped Windows shell guidance in `US-18`; `T-019` verifies the separately scoped end-of-loop lifecycle in `US-19`; `T-020` verifies the repository-wide terminal archive sweep in `US-20`. `T-021` through `T-026` exercise the separately scoped `uni-spec` applier in `US-21` through `US-26`; running an applier proves nothing about the standard's docs-only contract, which remains evaluated only by `T-007`.

## Evidence discipline

Every trace records observed text or structure, expected contract, and remediation where a rule fails. No trace treats a current workspace template as product authority, and no trace relies on forward or reverse authority links.
