# Ubiquitous language

## Terms

| Term | Meaning |
| :--- | :--- |
| upstream OpenSpec residue | A file, directory, identity, reference, script, or configuration inherited from the OpenSpec fork that is not required by the uni-spec goal or its contributor workflow. |
| required uni-spec artifact | A normative `standard/` document, `.arca/` working record, contributor rule, or explicitly evidenced supporting file needed to define or operate the uni-spec standard. |
| purge candidate | An observed path or reference proposed for removal, pending an evidence check that it is upstream residue and not a required uni-spec artifact. |
| minimal-retention set | The smallest evidence-backed set of required uni-spec artifacts preserved after the audit; anything outside it needs an explicit retention rationale. |
| sanitization | Removal of confirmed upstream identity, references, scripts, and configuration, together with cleanup of retained files that still point at the upstream fork. |
