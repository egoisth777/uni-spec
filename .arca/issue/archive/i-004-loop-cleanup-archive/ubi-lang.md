# Ubi language

## Terms

| Term | Meaning |
| --- | --- |
| Completed loop | A planning-and-building loop whose final green gap recheck has no `missing` or `partial` requirement and therefore satisfies the Idle gate. |
| Transient artifact | Reproducible generated output, installed dependency, cache, temporary fixture, or equivalent working artifact that is not retained authority, source, executable tests, evidence, or append-only history. |
| Current goal revision | The exact goal Git HEAD and ordered filename-NUL-content goal-bundle SHA-256 frozen for the completed loop and recorded in current state while `.arca/goal/` remains the cumulative authority. |
| Owning archive | The reserved `archive/` directory directly inside the issue, residual, or ticket collection that owns the terminal record. |
| Terminal record | A record belonging to the completed loop whose collection lifecycle is complete: an `integrated` or `rejected` issue, `satisfied` residual, or `done` ticket; active, pending, missing, partial, or otherwise unfinished records are nonterminal. |
| Archive-aware scan | A collection scan that excludes its reserved `archive/` and descendants from live shape, gap, or ticket work while still reserving every archived record identifier. |
